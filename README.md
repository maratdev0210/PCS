## Выводы

В ходе выполнения практической работы я познакомился с процессом интеграции Flutter-приложения с облачной платформой Firebase и освоил базовые операции с базой данных Cloud Firestore.

В рамках работы были выполнены следующие задачи:

+ создан новый Flutter-проект и подключен к Firebase с помощью FlutterFire CLI;

+ установлены и настроены пакеты firebase_core и cloud_firestore;

+ реализована инициализация Firebase при запуске приложения;

+ разработан экран для работы с заметками, поддерживающий все операции CRUD (создание, чтение, редактирование, удаление) в коллекции notes;

+ настроены тестовые правила безопасности Firestore и проверена их корректность;

+ протестирована синхронизация данных в реальном времени между приложением и базой данных.

+ В результате был создан полностью функционирующий блок для заметок, где все изменения мгновенно отображаются в интерфейсе благодаря реактивной модели Firestore.

Кроме того, использование Firebase показало себя удобным инструментом, который избавляет от необходимости самостоятельно создавать серверную часть — это особенно удобно для учебных проектов, MVP и прототипов.

Для полноценного промышленного использования необходимо:

1. подключить аутентификацию пользователей (firebase_auth);

2. усилить правила безопасности, например:

```bash
allow read, write: if request.auth != null;
```
3. предусмотреть обработку ошибок и валидацию данных.
