## 4.	Отчёт
В ходе работы были созданы три экрана с дизайном списка задач. Главный экран отвечает за запуск приложения. 
При нажатии на кнопку “Начать” открывается новый экран со списком задач. На экране со списком задач есть кнопка “+”, которая переводит пользователя на новый экран с добавлением задач. 
На экране с добавлением задач находится поле для ввода новой задачи и возможность ее сохранения. При нажатии на кнопку “Сохранить” пользователя перенаправляют на экран со списком задач. 
То же самое происходит и при нажатии на кнопку “Назад”.
